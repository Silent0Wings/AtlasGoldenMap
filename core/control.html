    All steps and options
    
    
  
    
    
    Setup
    
    
    
      
    
        
    Set up
    
        
    Installs what the atlas needs to run, including the test browser. Downloads can take a few minutes. If the app is not configured yet, it stops after this step and you continue with Configure.
    
        
    
        
      
    
      
    
        
    Install dependencies
    
        
    Installs the packages and the test browser if they are missing. Safe to run again. Does not touch your configuration.
    
        
    
        
      
    
      
    
        
    Configure
    
        
    Opens a short form with the same questions as the terminal setup: app name, how the app is run, its address, dark mode and phone view. Saves the atlas config file. If one exists, it is backed up before it is replaced.
    
        
    
        
      
    
    
    
  
    

  
    
    
    Capture and verify
    
    
    
      
      
    
    
    
    
      
    
        
    Capture
    
        
    Takes new screenshots of the app and compares them with the goldens. The first capture also runs Stabilize, so unsettled screenshots show up early. Approves nothing.
    
        
        
    
        
      
    
      
    
        
    Check
    
        
    Compares the app with the approved goldens and lists any differences. Approves nothing and changes no goldens.
    
        
    
        
      
    
      
    
        
    Stabilize
    
        
    Takes the screenshots several more times and lists the ones that do not come out the same twice. Takes a while. Approves nothing.
    
        
        
        
        
    
        
      
    
      
    
        
    Build atlas and open
    
        
    Captures everything, rebuilds the dashboard and opens it in your browser. Approves nothing.
    
        
    
        
      
    
    
    
  
    

  
    
    
    Approve
    
    
    
      
    
        
    Approve new
    
        
    Makes every new screenshot (one with no golden yet) an approved golden. You are asked to confirm first, and the count is shown.
    
        
    
        
      
    
      
    
        
    Approve all
    
        
    Approves every new, changed, stale or unsettled screenshot at once, replacing the old goldens. You are asked to confirm first. To check each one, use Open review.
    
        
    
        
      
    
      
    
        
    Open review
    
        
    Opens a page where you compare each screenshot with its golden, then approve or deny it one at a time. It runs only on this computer.
    
        
    Not running.

    Explore
    
    
    
      
    
        
    Rebuild dashboard
    
        
    Rebuilds the dashboard from the latest results and opens it in your browser.
    
        
    
        
      
    
      
    
        
    Open dashboard
    
        
    Opens the dashboard from the last build in your browser.
    
        
    
        
      
    
      
    
        
    Open test report
    
        
    Opens the test report from the last Check or Capture in your browser.
    
        
    
        
      
    
      
    
        
    Crawl links
    
        
    Visits the app and follows its links to list the pages it finds, then saves that list. Takes no screenshots and approves nothing.
    
        
    
        
      
    
      
    
        
    Discover navigation
    
        
    Looks through the app's menus and navigation and saves the links it finds. Takes no screenshots and approves nothing.
    
        
    
        
      
    
    
    
  
    

  
    
    
    Maintenance
    
    
    
      
    
        
    Clean
    
        
    Deletes the generated results: review data, screenshots, reports, the dashboard and the crawl lists. Approved goldens are kept unless you tick the box below. Your app's code is never touched.
